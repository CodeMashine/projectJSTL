Процесс работы:
заголовок блока/шага будет отображаться при выборе в предыдущем вопросе

при нажатии клавиши del блок удалятся , даже если в этот момент
редактируется этот блок

для входа в режим редактирования необходимо 2 раза кликнуть на блоке

для установления связи между блоками необходимо вабрать 2 блока
зажав клавишу ctrl и нажав на кнопку ADDLINE. 
связь сформируется между первым и вторым выбранным блоком.
